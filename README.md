# Airlyhub - Extreme Airplane Flight App

## Technology

- Xcode, Swift, Swift UIKit, SwiftUI
- RxSwift, SnapKit
- Mock Data

## Architecture

- VIPER

- Clone the repository using following command or download

```
git clone https://github.com/LeHaGiaBao/Airlyhub.git
```

- Open Xcode and Run App

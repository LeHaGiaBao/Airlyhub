# Airlyhub - Extreme Airplane Flight App

## Technology

- Xcode, Swift, Swift UIKit, SwiftUI
- RxSwift, SnapKit
- Mock Data

## Architecture

- VIPER

## UI design available here: [Figma](https://www.figma.com/community/file/1348042899657539399/flights-free-app-ui-kit)

## Requirements

- Xcode 16+
- [Tuist](https://tuist.dev)

## Installing

```bash
git clone https://github.com/LeHaGiaBao/Airlyhub.git
cd Airlyhub
tuist install
tuist generate
open Airlyhub.xcworkspace
```

Before running, add your Firebase iOS config file at `Airlyhub/GoogleService-Info.plist`.
This file is intentionally ignored by git.

## Development

After modifying `Project.swift` or `Tuist/Package.swift`, regenerate the project:

```bash
tuist generate
```

> Do not edit `Airlyhub.xcodeproj` directly — it is generated by Tuist and gitignored.
